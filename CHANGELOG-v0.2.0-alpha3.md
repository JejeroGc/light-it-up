# Light It Up v0.2.0 alpha 3

## Incluido
- Arquitectura de escenario con proscenio, viga superior, pared posterior y borde frontal.
- Varas metálicas con abrazaderas, cables y soportes visuales.
- Haz volumétrico de tres capas con núcleo, cuerpo y halo exterior.
