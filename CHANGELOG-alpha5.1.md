# Light It Up v0.2.0 alpha 5.1

## Corrección de regresión

- Restaurada la selección múltiple con Shift + clic.
- También se admite Command/Ctrl + clic para sumar o quitar luminarias.
- El arrastre directo ya no dispara una segunda selección al soltar el mouse.
- Restaurada la creación de grupos a partir de dos o más luminarias seleccionadas.
- Se mantienen las correcciones de playback automático, contraste de varas y drag directo de alpha 5.
