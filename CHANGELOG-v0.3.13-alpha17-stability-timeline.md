# Light It Up v0.3.13 — Alpha 17: Stability & Timeline Pass

- Cues no longer move or re-hang physical fixtures. Position/bar attachment belongs exclusively to the rig editor.
- Select All remains UI-only and no longer pollutes project history.
- Undo/Redo snapshots now include Programmer overrides, so position/intensity/color edits can be restored.
- Venue badge is dynamic (Auditorio Belgrano / Espacio Aguirre).
- Status bar updated to Alpha 17.
- Cue transition editor: double-click or right-click a cue to edit fade, delay, easing and stack multiple transition FX with independent mix and speed.
- Existing Rider Import guards for Belgrano/Aguirre retained.
