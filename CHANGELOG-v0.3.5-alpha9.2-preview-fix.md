# Light It Up v0.3.5 Alpha 9.2 — Timeline / Cue preview fix

- Timeline scrubbing now previews the latest cue at or before the playhead immediately.
- Seeking updates LIVE/NEXT state without requiring playback.
- Automatic cue loading/recording no longer clears physical rig-position Programmer overrides.
- This prevents fixtures arranged through Position overrides from collapsing back onto the same stored position when a cue is selected.
- Manual **Clear Programmer** remains available when the user intentionally wants to clear every override.
