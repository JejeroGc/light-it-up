# Light It Up v0.2.0-alpha.4

## Theatre identity pass

- Added optional-feeling theatrical architecture directly to the default stage: open house curtain, side legs and overhead borders.
- Improved stage depth while keeping the central design workspace unobstructed.
- Added fixture display panels and mounting clamps to Spot/Profile, Wash, Beam and Moving Head models.
- Unified interface accent, panel surfaces, focus states and viewport branding.
- Preserved cues, playback, timeline, groups, presets, selection, snap and transform gizmos.

## Scope note

Real manufacturer fixture libraries are intentionally not included yet. They require validated dimensions, photometric behavior and DMX profiles to avoid presenting fictional technical data.
