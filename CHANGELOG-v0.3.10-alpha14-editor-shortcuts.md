# Light It Up v0.3.10 — Alpha 14 Editor Shortcuts

- Added fixture Copy/Paste clipboard (Cmd/Ctrl+C, Cmd/Ctrl+V).
- Paste creates safe new fixture IDs and offsets copies for visibility.
- Unified common editor commands: Select All, Deselect, Group, Duplicate, Delete.
- Existing Undo/Redo remains handled by HistoryController.
- Edit menu now exposes shortcuts so commands are discoverable.
- Shortcuts are ignored while typing in inputs/textareas/contenteditable fields.
