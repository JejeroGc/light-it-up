# v0.3.11 — Alpha 15 Selection & Navigation

- Shift/Cmd/Ctrl + click preserves additive multi-selection.
- Arrow keys move all selected fixtures on the X/Z plane.
- Normal nudge: 0.10 m; Shift + Arrow: 0.50 m.
- Dragging on empty viewport creates a marquee selection rectangle.
- Shift + marquee adds fixtures to the current selection.
- Existing editor shortcuts and Rider Import flow are preserved.
- Keyboard editing is ignored while typing in inputs/textareas/contenteditable fields.
